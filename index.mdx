## Start Building in Minutes

<Steps>
  <Step title="Create Your Account">
    Sign up at [app.nexcore.io](https://app.nexcore.io) and create your first workspace. No credit card required for the free tier.
  </Step>
  <Step title="Install the SDK">
    Install the NexCore SDK for your preferred language and initialize the client with your API key.
    ```bash
    npm install @nexcore/sdk
    ```
  </Step>
  <Step title="Emit Your First Event">
    Send your first event to the NexCore stream and watch it appear in the real-time dashboard instantly.
    ```typescript
    import { NexCore } from '@nexcore/sdk';

    const client = new NexCore({ apiKey: 'YOUR_API_KEY' });

    await client.events.emit({
      stream: 'my-stream',
      payload: { action: 'user.signup', userId: '42' }
    });
    ```
  </Step>
  <Step title="Explore & Automate">
    Add AI analysis, connect pipelines, and configure webhooks to automate your workflows end to end.
  </Step>
</Steps>

<Note>
  NexCore's free tier includes 1 million events per month, 3 projects, and access to all core features. No credit card required.
</Note>
