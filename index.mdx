## Start Building in Minutes

Go from zero to a live event stream in four steps. No infrastructure provisioning, no cluster setup — just your API key and a few lines of code.

<Steps>
  <Step title="Create Your Account">
    Sign up at [app.nexcore.io](https://app.nexcore.io) and create your first workspace. The free tier includes 1 million events per month and 3 projects — no credit card required.
  </Step>
  <Step title="Install the SDK">
    Install the NexCore SDK for your preferred language and initialize the client with your project API key.

    ```bash
    npm install @nexcore/sdk
    ```
  </Step>
  <Step title="Emit Your First Event">
    Publish a structured event to your stream and watch it appear in the real-time dashboard instantly.

    ```typescript
    import { NexCore } from '@nexcore/sdk';

    const client = new NexCore({ apiKey: process.env.NEXCORE_API_KEY });

    const event = await client.events.emit({
      stream: 'user-actions',
      type: 'user.signed_up',
      data: {
        userId: 'usr_abc123',
        plan: 'free',
        source: 'web'
      }
    });

    console.log('Event published:', event.id);
    ```
  </Step>
  <Step title="Add AI Analysis and Pipelines">
    Attach an AI analysis step to your stream to classify, score, or enrich events inline — then route the results to any destination using a pipeline connector.

    ```typescript
    const analysis = await client.ai.analyze({
      stream: 'user-actions',
      model: 'anomaly-detector-v2',
      data: { userId: 'usr_abc123', eventCount: 142, sessionDuration: 30 }
    });

    console.log('Anomaly score:', analysis.result.score);
    ```
  </Step>
</Steps>

<Note>
  NexCore's **free tier** includes up to 1 million events per month, 3 projects, and 7-day event retention — no credit card required. Upgrade at any time from your workspace settings to unlock higher throughput, longer retention, additional team members, and enterprise features like SSO and data residency controls.
</Note>
